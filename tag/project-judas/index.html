Red Barrels lance Project Judas et célèbre 15 ans d’horreur montréalaise

Red Barrels a lancé la mise à jour Project Judas pour The Outlast Trials, marquant le 15e anniversaire du studio. Cette mise à jour enrichit le jeu avec de nouveaux contenus narratifs et mécaniques. Red Barrels, indépendant depuis 2011, est un modèle de réussite pour l’industrie du jeu vidéo au Québec.
